# 界读 · 离线伴读版 1.8

保留英文界面，逐句对照阅读，把不认识的词存进自己的生词本。

## 启动与使用

Windows 10 / 11 x64，需要 .NET Framework 4.8。完整解压文件夹，双击「界读.exe」。请将 ReadAlong.Reader.exe 和 Fonts 文件夹保留在程序旁。

1. 直接在主界面上方点击「开始伴读」，再切换到英文应用；同一按钮可暂停。
2. 主界面只显示逐句中英文；英文上方、中文下方。宽窗口可并列。
3. 点击英文单词，侧栏自动切到「取词」，核对或修改释义后收藏。
4. 「生词本」可以搜索、修改释义、标为掌握、移除、导出 CSV。导入 Anki 时跳过首行字段名。

启动默认暂停，不自动读取个人界面。默认每 1 秒检测一次，译文逐句出现。速度取决于识别与网络，相同内容会复用本次运行的缓存。

主界面会显示「正在识别当前窗口」「正在逐句翻译」或「伴读中 · 等待界面变化」。识别、翻译时，下方会有薄荷青到淡紫的光带扫过；任务结束或暂停后停下。不是百分比进度条。收成浮窗后，浮窗下沿也保留忙碌扫光。Windows 关闭客户端动画时使用静态提示。

## 窗口与文字缩放

- 主窗和小浮窗都可以拖动边缘、四角改变大小。
- 主窗上方的「− / 百分比 / +」调整对照文字大小，范围 70%–200%；点击百分比恢复 100%。
- 主窗内也可以按 Ctrl + 鼠标滚轮、Ctrl + 加号/减号调整文字，Ctrl + 0 恢复。阅读比例会自动保存。
- 小浮窗内 Ctrl + 滚轮，或右键菜单中的放大、缩小、恢复大小，可以独立调整浮窗，不会展开主窗。

## 收缩与展开

- 点击主窗右上角收缩图标，窗口会沿漏斗形路径吸入小浮窗。
- 单击小浮窗沿原路展开；途中再次切换可反向，不必等待。
- 拖动浮窗改变位置，靠近屏幕边缘释放会轻轻吸附。右键浮窗可展开、暂停/继续或退出。
- 收缩不是退出：如果此前开启了伴读，会继续处理当前窗口，小浮窗显示片段数量。
- 收缩不会自动暂停，也不会取消正在进行的识别或翻译。展开后保留伴读开关状态。
- 关闭主窗或在浮窗右键选择退出，才会停止程序。

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + Alt + T | 暂停 / 继续伴读 |
| Ctrl + Alt + M | 收缩 / 展开，支持途中反向 |
| Esc | 收起侧栏 |

快捷键被其他软件占用时，仍可使用窗口按钮或浮窗菜单。Windows 关闭客户端动画时，会直接切换状态，不播放空间动效。

## 侧栏

「伴读」页提供开始/暂停、重读、粘贴英文、置顶、先读英文和翻译设置。先读英文会隐藏中文，每句点「看译文」再展开。粘贴英文会暂停屏幕跟随，不自动读取剪贴板。

侧栏可以点击关闭、按 Esc 或拖动标题向右收起。侧栏内的生词本和取词不会替换主阅读内容。

## 配色、玻璃与字体

配色为薄荷青、淡紫和少量柠檬色。主阅读面保持清晰；句子使用轻阴影和细边界；侧栏使用应用内阅读内容的模糊采样、半透明着色与高光。工具条和浮窗使用半透明渐变，形成更轻的层次。

这不是 macOS 原生材质或原版 Genie 效果，是 Windows WPF 上实现的漏斗收缩近似。动画只渲染本应用的内存快照，不抓取其他应用或桌面作为玻璃背景。

- 英文原句、单词和例句：**Source Serif 4 Italic**，使用原生斜体字形，不是简单把正体倾斜。
- 中文译文和释义：**霞鹜文楷屏幕阅读版**，有手写气息，同时针对 PC 屏幕阅读优化。
- 菜单与操作按钮：系统无衬线字体，保持辨识度。

字体放在 Fonts 文件夹，不安装或修改系统字体。原始许可随文件附带，均按 SIL Open Font License 1.1 分发。请完整保留 Fonts。

来源：[Source Serif](https://github.com/adobe-fonts/source-serif)、[霞鹜文楷屏幕版](https://github.com/lxgw/LxgwWenKai-Screen)。本轮采用的设计 skill：[apple-design](https://github.com/emilkowalski/skills/tree/main/skills/apple-design)，已安装，本应用运行不依赖 skill。

扫光效果参考 GitHub 上的 [Shimmer](https://github.com/facebookarchive/Shimmer) 和 [flutter_shimmer](https://github.com/hnvn/flutter_shimmer)。本应用用 WPF 独立绘制，没有引入 iOS 或 Flutter 依赖，也没有复制这些项目代码。

## 翻译服务与限制

默认使用「本地离线（完全免费）」，无需密钥、没有每日字符额度。完整离线包内含中英模型和便携运行环境，识别和翻译均在本机完成。离线组件约占 218 MB 磁盘，不要求独立显卡。

从 GitHub 源码包首次启动时，launch.ps1 会自动下载并校验模型和组件，约 116 MB；下载完成后可断网翻译。也可在翻译设置中点击「安装离线翻译」。不会自动回退到在线翻译。

MyMemory 改为可选在线服务，不需要密钥。匿名额度为每天 5,000 字符，受服务端、共享网络额度和网络可达性影响。接近额度或限流时可手动切回本地离线。常用软件词及短语仍优先使用本地词库。

长期使用可以在侧栏设置切换自己的 Azure Translator（密钥与区域，可能计费）或 LibreTranslate（自己的服务地址，需提供 en 到 zh 模型）。本机地址可 HTTP，远程地址须 HTTPS。不附赠密钥或服务器。

[MyMemory API 与额度](https://mymemory.translated.net/doc/usagelimits.php)。

识别优先读取 Windows UI Automation 的可访问文字，读取不到再使用 Windows OCR。OCR 在本机完成。优先英语识别包，其他系统语言包也可能识别拉丁字母，但可能拆词；可在界读设置中打开 Windows 语言设置安装英语的光学字符识别功能。本程序不自动修改系统语言或安装系统组件。

部分受保护、管理员权限、游戏或显卡绘制窗口可能读不到，可用「粘贴英文」。OCR 与机器翻译可能误认，每次最多显示 70 条去重片段，较长句子按接口限制拆分。本机没有全面验证所有软件和混合 DPI 多显示器。

## 数据与隐私

- 仅处理当前前台窗口，不扫描后台或整个桌面。识别截图只留在内存，不保存、不上传。
- 默认离线模式下，文字不上传。只有手动选择在线服务时才发送待翻译文字；服务端按各自政策处理。界读不会再次识别自己的界面。
- 尝试跳过可识别输入框、密码框、网址、邮箱和疑似凭据行，不能保证过滤所有敏感内容；敏感页面请暂停。
- 只把主动收藏的词与原句写入生词本，不自动保存所有屏幕词句。普通翻译缓存只在本次运行中保留。
- 数据在程序旁 data/learning.json，备份为 learning.json.bak；读取损坏数据时会保留原文件，写入失败会提示并回退。
- 密钥用 Windows DPAPI 按当前账户加密，换电脑或账户后需重新填写。

迁移、更新或备份前先退出程序，保存整个 data 文件夹。程序应放在可写位置。

## 1.7 提速与滚动条

首次识别后复用独立识别进程与 OCR 引擎，暂停、退出或取消读取时会终止相应工作进程；收起窗口仍继续伴读。窗口文本使用 UI Automation 属性预取，减少跨进程查询。复杂控件树设有读取预算，超时仍可重试或粘贴英文。

默认 1 秒检测，切换前台窗口约每 250 毫秒检查一次。旧版默认 3 秒会迁移为 1 秒；已有 2 秒、5 秒选择保留，之后仍可在设置中自行调整。识别时间、检测等待与联网翻译时间不同，网络较慢时译文仍会等待。

相同英文再次出现时，会保留正在进行的翻译，避免反复取消；暂停后未完成的译文可在重新开始时继续处理。

滚动条改为无底槽的半透明细线，常态 4 像素，悬停或拖动时 6 像素；可拖动区域仍保留 12 像素宽，也支持滚轮、轨道翻页和键盘滚动。

## 1.7.1 行楷书页浮窗

小浮窗加入青绿书页徽标，主字标固定为「界读」，句数和伴读状态放在下方小字。表面增加内高光与轻柔阴影，右下角不再显示缩放花纹，仍支持拖动边缘改变大小。

字标优先使用本机已有的「华文行楷 / STXingkai」。没有安装的电脑回退为随包的霞鹜文楷。行楷字体不随程序分发；中文译文继续使用屏幕阅读版文楷。

## 1.7.2 折页图标

浮窗左侧重新设计为开放的翻页造型：青绿纸页、浅紫背页和微微翻起的浅色页，不带方形底座。图标使用矢量绘制，随浮窗缩放；状态和句数仍在行楷字标下方显示。

## 1.8 离线模式

设置中选择「本地离线（完全免费）」并保存即可使用。本机已完成安装时会显示「已就绪」，主界面状态旁也显示「本地离线」。首次加载模型会略慢，之后复用进程和缓存。暂停会取消正在进行的本地翻译，收起为浮窗不会停止伴读。

组件缺失、超时或翻译失败会在本机提示，不会自动发送文字到在线接口。检查或修复入口在翻译设置中；安装只需下载一次，日常翻译无需联网。中英模型许可与作者信息在 Offline/MODEL-NOTICE.txt，原始模型说明和运行库许可均保留。
