# 1.8 本机验证结果

48 项检查通过：14 项底层检查、27 项界面检查、7 项真实离线翻译检查。自动化识别仅使用自拟测试窗口，不读取个人界面；在线接口测试使用模拟响应。

## 真实离线翻译

使用实际 Argos en-zh 1.9 模型、CTranslate2 4.8.4 CPU int8 和 SentencePiece 0.2.2，处理不在本地短语表中的英文。

- 真实模型返回中文，HTTP 请求计数为零，即使每日字符计数已超额仍能翻译，计数不增加。
- 相同句子复用译文和工作进程。
- 并发排队请求各自得到正确的译文，不串句。
- 取消推理会停止工作进程，下一次请求可恢复。
- 缺失模型时提示安装。
- 未知服务类型不会自动回退到在线接口。
- Python 翻译工作进程明确拒绝建立网络连接。

示例：「Please select a folder to save your exported files.」实际译为「请选择要保存导出文件的文件夹。」。冷启动含模型载入约 1 秒；同机直接推理样例约 0.05–0.22 秒，不代表所有电脑、窗口或句子。

## 安装与验证边界

从官方来源下载了便携 Python、原始模型和四个 Windows wheel；wheel 与 PyPI 官方 SHA-256 一致，所有组件地址和校验值固定在安装清单。完整安装脚本已用下载缓存执行并通过真实模型自检。初次下载安装需要网络，日常离线翻译不需要网络。

未全面验证所有第三方软件、混合 DPI 多显示器或低配置硬件。离线译文可能不够准确；真实联网服务沿用此前验证，本轮不声称已对全部在线服务做实际网络测试。系统华文行楷不随包分发，未安装时回退到随包文楷。
